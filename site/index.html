HARA / PACKAGES

The reviewed package registry.

The registry of record lives in Git; this origin serves it read-only. Package objects are digest-addressed, so what you install is exactly what was reviewed.

/v1/registry The registry document, as EDN. Pinned to main or a commit. /.well-known/hara-tap.edn Tap discovery: name, identity, and registry coordinates. ./index.json Machine-readable registry index. hara-lang/hara-packages The Git repository of record. Review happens here. specs.hara-lang.org The normative Hara specifications.
